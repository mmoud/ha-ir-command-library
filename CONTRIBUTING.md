# Contributing

Thanks for helping improve IR Command Library. Keep changes focused, include a
short explanation of user-visible behaviour, and test the paths you touch.

Examples and fixtures must be fictional and generic. Never commit Home
Assistant backups, `.storage` content, learned IR/RF payloads, internal network
details, device identifiers, household names, or camera screenshots.

Before opening a pull request, run the validation commands in the README. For a
release, make sure the manifest version and dashboard-resource cache version
match the release tag.
